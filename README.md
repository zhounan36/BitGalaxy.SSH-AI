## 简介

BitGalaxy SSH AI 是一款面向日常运维与开发场景的 SSH 客户端：主机档案化管理、多标签终端、可视化 SFTP 文件管理、主机运行状态一览，并把 AI 助手直接整合进应用——**AI 帮你分析和规划，执行永远由你自己点击确认**。

单文件安装、独立数据目录、不常驻后台、点关闭即退出，干净利落。

## 特色功能

### 1. AI 助手（内置整合，永不越权）

- 右下角「AI」按钮随时唤起对话面板：流式输出、多轮上下文、历史记录落库保存
- 兼容 OpenAI 接口（默认 DeepSeek），在「设置 → AI 助手」里填入 API Key 即可用
- AI 可以**只读**查询你的主机清单、探测连通性、采集运行指标、浏览远程目录、读取远程小文件，用它来分析问题、解读日志
- AI **从不直接执行任何命令、不写任何文件**——它把要做的事变成候选命令交给你（见下）

### 2. AI 候选指令栏

- AI 规划的操作步骤（第一步、第二步、第三步…）会以命令列表形式固定在右下角指令栏
- 每条命令标注目标主机与用途说明，**点击即粘贴到对应主机的终端**（自动匹配主机名；本机命令则复制到剪贴板）
- 粘贴后不会自动执行，由你自己核对并敲回车——AI 出主意，你掌方向盘

### 3. 右键 · 问 AI

- 在终端里框选一段日志 / 报错 / 输出，右键「问 AI」
- 输入你的问题（选区自动附带为上下文），AI 助手面板自动弹出并开始分析
- "这段报错什么意思？""帮我把这个服务排查一遍"——选中即问，无需复制粘贴

### 4. 右键 · 直接下载 / 删除

- 选中 `ls` 输出里的文件或文件夹名，右键即可：
  - **下载**：经该会话 SFTP 直拉到本地，右下角浮层显示进度
  - **删除**：自动识别文件 / 文件夹，二次确认后执行（目录递归删除）
- 终端里看过的文件，不用再打开 FTP 工具

### 5. 拖拽 · 直接上传

- 从资源管理器把文件拖到任意终端面板上，松手即传
- 自动识别当前远端目录（shell 集成实时上报，登录目录兜底），多文件并行、进度浮层实时显示
- 上传完成自动收起，失败项保留供重试

### 6. 换行辅助 · 折行标记

- 一条长命令 / 长日志被终端列宽折成多行时，自动标注：续行行首 `↳` 箭头、折行块左侧竖线、块尾分隔线
- 一眼分清「一条长输出被折行」和「多行记录」，阅读日志、找命令边界不迷路
- 纯视觉覆盖层，不改动终端缓冲区——复制出来的仍是完整的原始逻辑行
- vim / top 等全屏程序自动关闭标注，渲染 / 滚动 / 缩放实时跟随；配合终端专注模式加宽窗口，等宽表更不易折行

## 快速开始

1. 下载安装包 `BitGalaxy SSH AI_x64-setup.exe`，双击安装（约 6 MB）
2. 左上角「新增主机」添加你的第一台 SSH 主机，单击主机名即开终端
3. 「设置 → AI 助手」填入 API Key（默认 DeepSeek，可改 Base URL 与模型），右下角点亮 AI

## 从源码构建

```bash
# 环境：Node 20+ / Rust (MSVC) / WebView2
npm install        # 安装依赖
npm run dev        # 开发调试（vite + tauri dev）
npm run build      # 产出 NSIS 安装包 target/release/bundle/nsis/
```

技术栈：Tauri 2 · Rust（russh / tokio / rusqlite）· React 19 · Ant Design 5 · xterm.js
